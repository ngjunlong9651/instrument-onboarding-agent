---
id: instrument-amendment
title: Amending static data on an existing instrument
workflow: instrument_onboarding
steps: escalate_to_human
---
Changes to an instrument that already exists (corrected coupon, new maturity after an exchange offer, issuer rename, corporate action) are not handled by the agent.

Escalate to the static data team with the requested change and evidence. Amendments to live instruments affect open positions and need four eyes review.
